# エレベーターピッチ

AI Codingによって実装スピードは向上した一方で、企画フェーズにおけるリサーチ、ペルソナ設計、ユーザーインタビュー、業務理解がボトルネックになっている課題を解決したい。

PdMやプロダクト開発チーム向けの、

ペルソナOps（ペルオプ）は、

AIプロダクトディスカバリープロダクトである。

これは、GitHubのソースコード、プロダクトの操作方法、過去のユーザーインタビューなどをアップロードしエージェントと会話するだけで、業務フローを理解した仮想ペルソナ群を生成し、機能追加によるユーザー影響を実装前に検証できる。　

従来のユーザーインタビュー、ペルソナシート、開発者同士の壁打ちとは違って、

機能追加案をペルソナ群に投げることで、誰が喜び、誰が困り、どの業務フローに摩擦が生まれるかをシミュレーションできる機能が備わっている。
